# Coding-agent adapter

This file only points coding agents to the repository's shared instructions. It is not a source
of product behaviour or development policy.

Before changing files, read:

- [`CONTRIBUTING.md`](CONTRIBUTING.md) for the contributor entry point;
- [`docs/development/README.md`](docs/development/README.md) and the linked development policy;
- [`docs/development/issue-lifecycle.md`](docs/development/issue-lifecycle.md) for Issue states;
- [`docs/workflows/implement-feature.md`](docs/workflows/implement-feature.md) for implementation;
- [`docs/workflows/triage-issue.md`](docs/workflows/triage-issue.md) when triage was requested;
- the relevant files under [`specs/`](specs/README.md) and architecture constraints.

After reading these documents, follow the same Issue-driven process as human contributors.
